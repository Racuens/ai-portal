# AI Portal — Laboratory Work No. 9

Responsive website for the ICT6001 Lab 9 brief.

## Files
- `index.html` — semantic HTML layout and mobile navigation/theme toggle
- `style.css` — responsive CSS Grid/Flexbox, mobile and desktop breakpoints, light/dark theme
- `images/` — reserved for exported assets (the hero artwork is built with CSS)

## Run locally
Open `index.html` in a browser, or use Live Server in Visual Studio Code.

## Publish on GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload `index.html`, `style.css`, and this README to the repository root.
3. In **Settings → Pages**, select deploy from the `main` branch and `/ (root)`.
4. Save and wait for the public Pages URL to appear.

## Suggested commit sequence
- `feat: add semantic AI portal structure`
- `feat: build responsive grid and hero section`
- `feat: add mobile navigation and theme toggle`
